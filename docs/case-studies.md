# Case Studies

## Case Study 1: Reducing onboarding friction

### Context
A B2B SaaS team saw activation plateau despite rising trial signups.

### Insight synthesis
Cross-channel feedback clustering revealed repeated confusion around team invitation setup and permission language.

### Product action
- Reworked onboarding IA
- Added progressive disclosure on permissions
- Introduced contextual help based on user role

### Outcome
- +18% activation rate
- -24% onboarding support tickets
- Faster time-to-first-collaboration

## Case Study 2: Prioritizing reliability over feature volume

### Context
NPS dropped while feature velocity remained high.

### Insight synthesis
Feedback themes showed core dissatisfaction tied to performance regressions, not missing features.

### Product action
- Created reliability sprint lane
- Added performance guardrails to release criteria
- Delayed two roadmap features to recover baseline quality

### Outcome
- +11 point NPS improvement over 2 quarters
- Reduced churn risk among key enterprise accounts

## Case Study 3: Improving experiment hit rate

### Context
Team was running many A/B tests with low win rate.

### Insight synthesis
Problem statements were too solution-first and weakly tied to user pain evidence.

### Product action
- Standardized problem framing template
- Required evidence strength scoring before experiment approval
- Added pre-mortem review for major tests

### Outcome
- +14% experiment win rate
- Better cross-functional confidence in product bets
